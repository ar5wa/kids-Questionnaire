# دار حصه الثاقب الصباحيه — استمارة تسجيل الاجيال 

موقع استبيان بهوية "دار حصه الثاقب"
## الملفات
- `index.html` — الموقع كامل (تصميم + المنطق)، شغّليه بفتحه في أي متصفح.
- `apps-script/Code.gs` — كود الخادم البسيط (Google Apps Script) اللي يستقبل الردود ويخزنها.

## خطوات التشغيل (٣ خطوات)

### ١) جهّزي مكان تخزين الردود
1. افتحي [sheets.google.com](https://sheets.google.com) وسوّي شيت جديد فاضي، سميه مثلاً "ردود دار الأجيال".
2. من القائمة فوق: **Extensions ← Apps Script**.
3. امسحي أي كود موجود، والصقي محتوى ملف `apps-script/Code.gs` كامل.
4. فوق يمين: **Deploy ← New deployment**.
5. اختاري نوع **Web app**، وحطي:
   - Execute as: **Me**
   - Who has access: **Anyone**
6. دوسي **Deploy**، وهتطلب منك صلاحيات (وافقي عليها لأنه حسابك أنتِ).
7. انسخي الرابط اللي يطلع (**Web app URL**).

### ٢) اربطي الموقع بالشيت
افتحي `index.html` بأي محرر نصوص (أو VS Code)، ودوري على هذا السطر تحت في نهاية الملف:
```js
const GAS_URL = "PASTE_YOUR_GOOGLE_APPS_SCRIPT_URL_HERE";
```
واستبدلي الرابط بالرابط اللي نسختيه. احفظي الملف.

### ٣) عدّلي بيانات الحساب البنكي
في قسم "الدفع" داخل `index.html` فيه بيانات حساب وهمية (رقم حساب/آيبان) — بدّليها ببيانات دار الأجيال الحقيقية قبل ما تنشرين الموقع.

### نشر الموقع مجانًا (اختياري)
بعد الرفع، من إعدادات الريبو في GitHub: **Settings ← Pages ← Deploy from branch ← main** — بيديكِ رابط مباشر تقدرين ترسلينه لأي أحد يعبّي الاستمارة.
